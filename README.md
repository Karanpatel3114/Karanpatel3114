|---|---|---|
| **[JoinPilot](https://github.com/Karanpatel3114/joinpilot)** · [Live demo](https://joinpilot.vercel.app) | An AI agent that turns raw ERP tables and a plain-English requirement into a tested, human-approved data model: evidence-backed joins, guarded SQL views, automated integration checks, a KPI dashboard, plain-English questions and an MCP server. *FastAPI, LangGraph, DuckDB, Postgres, React* | 0.993 join F1 on held-out data (best baseline 0.868); 1,248 of 1,248 KPI values correct; 71 of 71 SQL attacks blocked |
